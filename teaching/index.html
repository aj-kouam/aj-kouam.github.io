Teaching activities

I had the opportunity to teach and supervice students cross multiple institutions and academic levels through a variety of course formats, including Massive Online Open Courses (MOOC), Practical Courses (PC), Seminar Courses (SC), and Lecture Tutorials (TD). Open science & Open-source

ZenPlus Library

Python library for modeling traffic–mobility dependencies from fine-grained mobile network data.

En-WDM Mobility Model

Enhanced Working Day Mobility simulator for generating mobility-rich mobile datasets.

FraudZen Simulator

Simulator for traffic and mobility of legitimate and SIMBox users in cellular networks.

FraudZen Dataset

Realistic mobile traffic traces with ground truth generated with the FraudZen simulator for benchmarking SIMBox fraud detection algorithms.

SigN Dataset

Dataset and scripts for SIMBox latency anomaly detection at the cellular edge.

MSMDF Dataset

Motion sensor fingerprinting dataset collected across 42 smartphones under diverse conditions.
